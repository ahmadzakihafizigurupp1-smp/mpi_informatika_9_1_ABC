Mengenal Struktur & Visualisasi Data

Data dalam komputer tidak hanya sekadar disimpan, tetapi harus diatur secara terstruktur. Cara mengatur data secara efisien disebut Struktur Data. Sementara itu, Visualisasi Data adalah teknik menyajikan data tersebut menjadi gambar atau grafik agar mudah dipahami oleh manusia.

Tree (Pohon)

Struktur data hierarkis yang memiliki tingkat (level), di mana ada satu titik awal (root) dan bercabang ke bawah.

Graph (Graf)

Struktur data yang menyerupai jaringan, menghubungkan titik-titik (node) melalui garis (edge) tanpa aturan hierarki yang ketat.

Visualisasi

Teknik penerjemahan data terstruktur menjadi bentuk visual (grafik, diagram) agar dapat dianalisis dengan cepat.

Struktur Data Tree

Tree (Pohon) adalah struktur data non-linear yang menyerupai bentuk pohon terbalik. Elemen dasar dalam tree disebut Node (simpul).

Root (Akar)

Node paling atas dalam hierarki. Tidak memiliki parent (induk).

Leaf (Daun)

Node yang berada di paling bawah dan tidak memiliki child (anak).

Struktur Data Graph

Graph (Graf) adalah struktur data yang menyerupai jaringan bebas. Setiap titik dapat terhubung dengan titik mana saja.

Node / Vertex

Merupakan entitas atau titik dari sebuah graph.

Edge / Sisi

Garis penghubung antar dua buah Node.

Visualisasi Data

Bar Chart (Batang)

Membandingkan jumlah antar kategori.

Line Chart (Garis)

Menunjukkan tren perubahan data.

Pie Chart (Lingkaran)

Menunjukkan persentase suatu bagian.
