Mengenal Struktur & Visualisasi Data

Data dalam komputer tidak hanya sekadar disimpan, tetapi harus diatur. Cara mengatur data secara efisien disebut Struktur Data. Sementara itu, Visualisasi Data adalah teknik menyajikan data tersebut menjadi gambar atau grafik agar mudah dipahami oleh manusia.

Tree (Pohon)

Struktur data hierarkis yang memiliki tingkat (level), di mana ada satu titik awal (root) dan bercabang ke bawah.

Graph (Graf)

Struktur data yang menyerupai jaringan, menghubungkan titik-titik (node) melalui garis (edge) tanpa aturan hierarki yang ketat.

Visualisasi

Teknik penerjemahan data terstruktur menjadi bentuk visual (grafik, diagram) agar dapat dianalisis dengan cepat.

Sub-Topik A

Struktur Data Tree

Tree (Pohon) adalah struktur data non-linear yang menyerupai bentuk pohon terbalik. Struktur ini bersifat hierarkis. Elemen dasar dalam tree disebut Node (simpul).

Root (Akar)

Node paling atas dalam hierarki. Tidak memiliki parent (induk).

Leaf (Daun)

Node yang berada di paling bawah dan tidak memiliki child (anak).

Sub-Topik B

Struktur Data Graph

Berbeda dengan Tree yang harus memiliki struktur atas-bawah, Graph (Graf) adalah struktur data yang menyerupai jaringan bebas. Setiap titik dapat terhubung dengan titik mana saja.

Node / Vertex

Merupakan entitas atau titik dari sebuah graph. Representasi dari sebuah objek.

Edge / Sisi

Garis penghubung antar dua buah Node. Bisa memiliki arah atau tanpa arah.

Sub-Topik C

Visualisasi Data

Visualisasi Data adalah proses menerjemahkan sekumpulan data mentah yang kompleks menjadi bentuk grafis seperti diagram, peta, atau grafik.

Bar Chart (Batang)

Membandingkan kuantitas/jumlah antar kategori yang berbeda.

Line Chart (Garis)

Menunjukkan tren perubahan data seiring berjalannya waktu.

Pie Chart (Lingkaran)

Menunjukkan persentase suatu bagian terhadap keseluruhan.
